# POS

[![CI Pipeline](https://github.com/slimchouaib1/POS/actions/workflows/ci.yml/badge.svg)](https://github.com/slimchouaib1/POS/actions/workflows/ci.yml)

Intelligent POS web application for cafe and restaurant management, integrating sales, stock, dashboards, and AI modules for recommendation, forecasting, anomaly detection, and customer segmentation.

## Docker

Copy `.env.example` to `.env`, replace the placeholder passwords and secrets, then start the stack from the repository root:

```bash
docker compose up -d --build
```
